# Framo – instalator

**[Pobierz Framo.dmg](https://github.com/sygnaturazdrowia/framo-instalator/raw/main/Framo.dmg)** – Framo 1.33.0 (build 245), Apple Silicon i Intel, macOS 15 lub nowszy.

Instalacja: otwórz Framo.dmg i przeciągnij Framo do folderu Aplikacje. Przy pierwszym uruchomieniu macOS może
zablokować program (nie pochodzi z App Store) – wtedy Ustawienia systemowe → Prywatność i ochrona → „Otwórz mimo to”.
Kolejne wersje Framo pobiera i instaluje samo (appcast.xml i paczki Framo-*.zip w tym repozytorium).
